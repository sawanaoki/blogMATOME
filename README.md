# バズ話題・ニュースまとめブログ自動作成ツール

X（Twitter）のトレンド話題や最新ニュースを自動収集し、Google Gemini APIを活用してライブドアブログ（livedoor Blog）向けのまとめ記事（HTML形式）を自動生成・投稿するWebアプリケーションです。

---

## 主な機能

1. **情報収集 (Collectors)**
   - **Yahoo!リアルタイム急上昇トレンド**: 今まさにXでバズっているキーワードを自動取得。
   - **Xポスト収集（API不要）**: Yahoo!リアルタイム検索の話題ツイートを自動スクレイピングで収集。
   - **Google News RSS**: 主要ニュースやジャンル別（エンタメ、テクノロジー、国内など）の最新記事を取得。
   - **キーワード自由検索**: 任意の単語を入力して関連ニュースとXポストを一括検索。
   - **X公式API拡張枠**: 将来的に有料プランのアカウントを契約した際、直接X API v2と連携可能。

2. **まとめ記事自動生成 (Gemini API)**
   - 思わずクリックしたくなるキャッチーなタイトル案を複数生成。
   - ニュース概要、経緯、ネットの反応（肯定・否定・ユーモア・考察の分類）、管理人の総括で構成。
   - トーン指定（王道まとめブログ風、2ch・5chスレ風、解説ニュース風、辛口考察風）。
   - ライブドアブログで美しく装飾されるインラインスタイルHTML形式で出力。

3. **編集・プレビュー・投稿 (Publisher)**
   - ブラウザ上で仕上がりのブログ見た目をプレビュー確認。
   - タイトル候補のワンクリック切り替え、HTMLコードの直接編集。
   - **ライブドアブログ AtomPub API 投稿**: ワンクリックで「下書き保存」または「公開投稿」。
   - **ワンクリックHTMLコピー**: APIキーを設定しなくても、エディタにそのまま貼り付け可能。
   - **ローカル自動保存**: 生成した記事を `output/` フォルダに日時付きでHTML保存。

## 使い方

### 1. 起動方法
フォルダ内の `run.bat` をダブルクリックするか、ターミナルで以下を実行します：

```bash
python -m streamlit run app.py
```

自動的にブラウザ（`http://localhost:8501`）が開きます。

### 2. 初期設定（画面または `.env`）
1. 画面左側のサイドバー **「Google Gemini API 設定」** にAPIキーを入力します。
   - APIキーは [Google AI Studio](https://aistudio.google.com/) で無料で即時取得可能です。
2. ライブドアブログに直接投稿したい場合は、**「ライブドアブログ設定」** に `livedoor ID` と `API Key` を入力します。
   - ライブドアブログ管理画面 >「ブログ設定」>「API Key」で確認できます。
   - ※未設定でも「HTMLコピー」機能で手動貼り付けが可能です。

### 3. 記事作成の流れ
1. **話題を選ぶ**: Yahoo!急上昇トレンド、Googleニュース、または自由検索から気になる話題を選択し「情報を収集する」をクリック。
2. **ポストの確認**: 収集されたXのポスト一覧を確認（採用・除外を選択可能）。
3. **記事を生成**: 「Geminiでまとめブログ記事を自動生成する」ボタンをクリック。
4. **確認＆投稿**: プレビューを確認し、タイトルや内容を微調整して「ライブドアブログへ送信」または「HTMLコードをコピー」！

## フォルダ構成
```text
blogMATOME/
├── run.bat                   # 起動バッチ
├── app.py                    # Streamlit Webアプリ本体
├── requirements.txt          # 依存パッケージ
├── .env.example              # 設定ファイルテンプレート
├── output/                   # 生成記事の自動保存先
├── src/
│   ├── config.py             # 設定管理
│   ├── collectors/           # 情報収集（Yahoo!リアルタイム、Google News、X API）
│   ├── generator/            # Gemini API 記事生成・プロンプト
│   └── publisher/            # ライブドアブログ投稿・保存
└── docs/
    └── summary_blog_generator/
        ├── task.md
        ├── implementation_plan.md
        └── walkthrough.md
```
