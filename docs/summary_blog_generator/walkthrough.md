# まとめブログ自動作成ツール 実装・修正内容の確認 (Walkthrough)

バズったX（Twitter）の投稿や最新ニュースを取り上げ、Google Gemini APIを活用してライブドアブログ（livedoor Blog）向けのまとめ記事を自動生成・投稿するWebアプリケーションを構築しました。

---

## 1. 実装内容の概要

### ① 情報収集モジュール (`src/collectors/`)
- **Yahoo!リアルタイム検索 (`yahoo_realtime.py`)**:
  - API不要で、今まさに盛り上がっている急上昇トレンドワード一覧（20〜30件）を自動取得。
  - 各キーワードに関連するXのツイート本文・投稿者・リンクをリアルタイムにスクレイピングで抽出。
- **Google News RSS (`google_news.py`)**:
  - 総合トップニュースのほか、エンタメ、テクノロジー、国内などの主要ジャンル別RSSを取得。
  - キーワード検索によるニュース記事のピンポイント取得も対応。
- **X (Twitter) 公式API拡張枠 (`twitter_api.py`)**:
  - ご要望にあった「将来有料プランを契約した際に対応できる箱」として実装。
  - Bearer Token等を `.env` またはUIから設定すれば、公式API v2の検索（`/2/tweets/search/recent`）をそのまま実行可能。

### ② 記事生成モジュール (`src/generator/`)
- **まとめブログ特化プロンプト (`prompts.py`)**:
  - 【悲報】【朗報】【衝撃】などのキャッチーな見出し候補（メイン＋複数案）の生成。
  - 事件・話題の概要・背景の整理。
  - ネットの反応（肯定・否定・ユーモア・考察の分類とレス風レイアウト）。
  - 管理人の総括・考察。
  - ライブドアブログをはじめ、どのブログテンプレートでもデザイン崩れを起こさないインラインCSS装飾HTML形式で出力。
- **Gemini API クライアント (`gemini_client.py`)**:
  - 最新の `google-genai` 公式SDKを採用。
  - JSON Schemaベースの安定したレスポンス抽出。

### ③ ライブドアブログ投稿 & 保存 (`src/publisher/`)
- **AtomPub API連携 (`livedoor_client.py`)**:
  - ライブドアブログのAtomPub API経由で、「下書き（Draft）」または「公開（Publish）」投稿を実行。
  - 投稿完了後、および「ローカル保存」ボタンから、日時付きで `output/` フォルダへHTMLバックアップを自動保存。

### ④ ユーザーインターフェース (`app.py` & `run.bat`)
- **Streamlit Web画面**:
  - **4ステップ形式**:
    1. **話題選び**: Yahoo!トレンド / Googleニュース / 自由検索の3タブから選択。
    2. **データ確認**: 収集されたXポストの一覧プレビュー＆不要ポストの除外チェックボックス、記事トーンの選択。
    3. **自動生成**: ワンクリックでGeminiが記事執筆。
    4. **プレビュー・編集・投稿**: タイトル候補の切り替え、実際のブログ見た目のリアルタイムプレビュー、HTML直接編集、ワンクリックHTMLコードコピー、ライブドアブログ投稿。
- **ワンクリック起動バッチ (`run.bat`)**:
  - ダブルクリックするだけでStreamlitアプリが起動。

### 5. 俺的ゲーム速報・はちま起稿風スタイルの強化 & 管理人のひとこと編集
- **プロンプトおよびCSS装飾の拡充**:
  - 【狂気】【速報】【草】などの煽り角括弧プレフィックス付きインパクトタイトル。
  - 管理人のハイテンションな叫び導入。
  - まとめブログ黄金比の装飾（強烈なパンチライン＝赤太字 `<span style="color: #d9534f; font-weight: bold; font-size: 1.15em;">`、冷静なツッコミ＝青太字 `<span style="color: #0275d8; font-weight: bold;">`、太字・草リアクション）。
- **管理人のひとこと専用の個別編集UI**:
  - HTMLコードを意識することなく、「管理人のひとこと」の文章だけを直感的に書き換えられる専用テキストエリアを設置。
  - 入力されたテキストが自動的にデザイン枠に整形され、プレビュー・HTMLコピー・ライブドア投稿に即時連動。
- **最新Geminiモデル対応**:
  - `gemini-2.5-flash`（超高速・最新標準モデル）および `gemini-2.5-pro`（高度推論モデル）を正式サポート。
- **Streamlit Community Cloud / GitHub 連携準備**:
  - `st.secrets` と `.env` のハイブリッド構成に対応し、クラウド上でも安全にAPIキーを秘匿管理可能に。
  - `.gitignore` を整備し、安全にGit初期コミット（`main` ブランチ）を完了。

## 3. アプリケーションの起動と使い方

1. **起動**:
   - フォルダ内の [run.bat](file:///d:/ソフト開発/blogMATOME/run.bat) をダブルクリックします。
   - または、ターミナルで `python -m streamlit run app.py` を実行します。
2. **初期設定**:
   - 画面左側のサイドバーで **Gemini API Key** を入力します（[Google AI Studio](https://aistudio.google.com/) で取得可能）。
   - ライブドアブログに直接投稿したい場合は **livedoor ID** と **API Key** も入力します。
3. **記事作成**:
   - トレンドまたはニュースを選択 → ポストを確認 → 「Geminiでまとめブログ記事を自動生成」をクリック。
   - プレビューを確認し、「ライブドアブログへ送信」または「HTMLコードをコピー」して記事投稿完了です！
